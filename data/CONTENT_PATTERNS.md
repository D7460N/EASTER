# Content Patterns Analysis

## Overview
This document summarizes the content patterns identified across all 39 documents in the EASTER repository.

## Document Structure Pattern

All content files follow this consistent structure:

### 1. YAML Front Matter
```yaml
---
id: category/topic                          # Unique identifier
category: Category Name                     # One of 7 main categories
tags: [keyword1, keyword2, keyword3]        # Search/filter keywords
audience: [role1, role2]                    # Target readers
summary: "One-sentence description"         # Brief overview
scriptural_reference: "Book Chapter:Verse"  # Optional Bible reference
related: [id1, id2]                         # Optional cross-references
---
```

### 2. Opening Scripture Quote
Most documents begin with an inspirational quote:
```markdown
> "Quote text"
> — _Biblical Reference_
```

### 3. Structured Content
- Clear hierarchical headings
- Practical guidance and best practices
- Lists and tables for clarity
- Application sections

## Metadata Standards

### ID Convention
Pattern: `category/topic-name`
- Examples: `intro/vision`, `acting/blocking`, `roles/director`
- Lowercase with hyphens
- Category prefix for namespacing

### Summary Format
- Single sentence
- Descriptive and action-oriented
- Typically 8-15 words
- No ending period

### Tags
- 2-5 tags per document
- Single words or hyphenated phrases
- Lowercase
- No duplicates within a document
